# 08 Wrap-up

Learner guide: [08 Wrap-up](../learner/08-wrap-up.md)

## Instructor notes

- Keep this as a synthesis, not another feature tour.
- Restate the loop: trace behavior, detect signals, collect examples, run experiments, compare changes.
- Ask which one piece they would apply to their own app first.
- Point at the Langfuse skill and `npx langfuse-cli` for the codebase they go back to. This repo's Python patterns (`@observe`, `langfuse.openai.OpenAI`, `get_prompt`, `dataset.run_experiment`) are the ones to copy.

## Good closing prompts

- Which trace view changed how you would debug an LLM app?
- Which monitor would you create first for your own product?
- What real examples would seed your first dataset?
